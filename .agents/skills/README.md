# Tuition Serve Skills Bundle

This bundle contains project-specific engineering and QA skills for the Tuition Serve web application.

## Structure

Each skill is stored in its own directory and each directory contains a `SKILL.md` file.

## Included skills

- requirements-compliance
- uiux-visual-qa
- qa-adversarial-testing
- e2e-release-validation
- debugging-root-cause
- security-audit
- performance-engineering
- production-devops
- tutor-lifecycle
- tuition-workflow
- domain-data-integrity
- role-authorization
- location-data-engineering
- location-privacy
- notification-engineering
- messaging-engineering
- document-file-security
- uiux-product-fidelity

## Deliberately excluded from this project

The old Kirana-specific `financial-integrity` and `inventory-integrity` skills are not included because they are unrelated to Tuition Serve's business domain.

## Expected usage

Load the skills alongside the Tuition Serve PRD, role matrix, UX flows, wireframe specification, domain model, TRD, and implementation plan. The skills provide implementation guardrails; they do not replace the product documents.
